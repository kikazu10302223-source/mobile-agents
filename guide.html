1. 全体の流れ

STEP 1ネタを集める（AIが5分）
STEP 2仕込む（5〜15分）
STEP 3あなたが加筆（10分）
STEP 4承認する（1分）
STEP 5noteに投稿（10分）

働くのは9人 ── トレンド編集者（ネタ選別）・編集長・需要分析・リサーチ・深掘り・執筆・QA・図解・SNS。
加えて機械が2つ働きます。ネタの材料集め（AIの回数を使わない）と、記事の自動検査です。

2. 準備（最初の1回だけ）

  1. https://kikazu10302223-source.github.io/mobile-agents/app.html をダブルクリック（インストール不要・ブラウザで動きます）
  2. 右上の 「キーを設定」 を押す
  3. Google AI Studio でAPIキーを作り、AIza… を貼る
  4. 「保存して確認」 を押す → 「使えるモデルを◯件…」と出れば成功
無料プランの場合：1分・1日あたりの回数に上限があります。この仕組みは1回ごとに6秒あける「慎重モード」を最初からONにしています。また無料プランでは入力内容がGoogleの製品改善に使われます。売るための企画を外部に出したくない場合は、有料プラン（従量課金）をご検討ください。

キーを入れずに動作だけ試すこともできます：https://kikazu10302223-source.github.io/mobile-agents/app.html?trial=1 で開くと練習モード（AIは呼ばず、見本の出力）になります。

3. ネタを集める（AIが選別する）

3-1. 材料を用意する（任意・推奨）

黒い画面（ターミナル）でこのフォルダに移動し、次を実行します。

python3 trend_collect.py --plain --out 材料.txt

材料.txt を開いて全文コピーし、画面の 「材料」欄に貼り付けます。
この材料は、ITmedia Mobile / はてなブックマーク / Yahoo!ニュース / 総務省 の公開フィードから集めた「いま動いている話題」です（2026年9月時点で応答を確認済み）。

やることコマンド
材料を集める（AIに貼る用）python3 trend_collect.py --plain --out 材料.txt
取得先が生きているか確認python3 trend_collect.py --check
語で絞る（例：光回線）python3 trend_collect.py --keyword 光回線 --plain
自分で拾った断片を混ぜるpython3 trend_collect.py --paste x_posts.txt --plain
X（旧Twitter）からの自動収集はできません。2026年2月にX APIは従量課金へ移行し、新規では実質的に無料枠が無くなりました。さらにXの利用規約が自動収集を禁止しています。
代わりに、あなたが目で拾った投稿を数行コピーして x_posts.txt に貼り、材料に混ぜてください。現場の嗅覚がそのまま活きます。

3-2. AIに選ばせる

  1. 「AIにネタを集めさせる」欄の材料を貼る（空でもOK。その場合はAIが記憶から提案し、【仮説】【要確認】と明記します）
  2. 「ネタを選ばせる（5〜10件）」 を押す
  3. ネタ候補がカードで出ます。各カードには切り口・話題度・賞味期限・先に確認すべき一次情報・根拠が付きます
  4. 「このネタで作る」 を押すと制作が始まります。「ネタ帳に足す」 でまとめ仕込みに回せます

4. ネタを直接入力して1本作る

  1. テーマを入力（例：光回線の乗り換えで損しない手順）
  2. ジャンルを選ぶ（モバイル/通信、光回線、デバイス、料金・契約 など）
  3. 想定読者・調べたいことを入れると、精度が上がります（任意）
  4. 「このテーマで作る」 を押す

8つの役割が順に働き、最後に検査まで済ませてストックへたまります。

5. まとめて仕込む（ストック）

  1. ネタ帳に1行1テーマで3〜5行を貼る（AIの候補から「ネタ帳に足す」でもOK）
  2. 「まとめて作る（ストックへ）」 を押す
ボタン意味
中止する次の1本が終わってから安全に止まります
ストックを書き出す全記事＋検査＋SNS投稿を1ファイルに。こまめに退避してください
ストックを空にするブラウザの保存を整理します（消えるので先に書き出しを）
ストックはブラウザの中に保存されます。20〜30本を超えると保存容量に近づきます。またブラウザのデータを消すとストックも消えます。月に一度は「書き出す」を押してください。

6. 承認する（あなたの出番）

左の「ストック」から1本を開きます。やることは3つです。

  1. 本文を読む（「検査レポート」タブでERRORが残っていないか確認）
  2. あなたの店頭体験を1つ足す ── 実際にお客様から聞かれたこと、手続きでつまずく点、店頭とオンラインの違い。これが他サイトとの決定的な差です
  3. 「承認する」（却下するときは理由を必ず書く。理由は次回の企画に自動で反映されます）

7. 発信する（X・Instagram・TikTok）

記事ができたら、それを人に届ける入口を作ります。「発信」タブの3つのボタンだけで進みます。

  1. 「発信」タブを開きます。
  2. 「どの記事から作りますか」で記事を選びます（選ぶと「本文○○字を使います」と表示されます）。手元の原稿を使うときは、下の欄に貼り付けても作れます。
  3. 作りたい媒体のボタンを押します（Xの投稿文を作る／Instagramを作る／TikTok台本を作る）。30秒〜2分ほどでできます。
  4. コピーを押して、各アプリに貼り付けます。Xは「Xの投稿画面を開く」を押すと、文面が入った状態でXが開きます（あとは投稿を押すだけです）。

Xは投稿文を3案（速報型・比較型・体験型）作ります。無料アカウントの文字数は全角140字なので、超えないように作らせています。Instagramはキャプション（1行目でつかむ）とタグ10個前後、画像に載せる文字を2案作ります。TikTokは20〜30秒の縦動画の台本を、つかみ・本題・締めに区切り、読み上げ原稿と画面テロップに分けて作ります。

自動投稿・予約投稿はできません。理由は3つです。(1) InstagramとTikTokは各社の審査と開発者登録が必要です。(2) この仕組みはブラウザだけで動くため、秘密の鍵（アクセストークン）を安全にしまっておくサーバーがありません。公開ページに鍵を置くのは事故のもとなので、やりません。(3) Xは従量課金で、ブラウザから直接呼ぶとCORS（別サイト間の通信を制限する仕組み）で拒否されます。
予約投稿まで自動化したいときは、SocialDog・Buffer・Meta Business Suite などの予約投稿サービスに渡すのが、安全で安上がりです。

どの媒体にも共通で、記事に書いていない数字を足さない／金額には基準日を書く／「最安」「絶対」を使わない／広告は「PR」と明記するというルールで作らせています。記事のURLは勝手に作らず「【記事URL】」と空けてあるので、ご自身で貼ってください。

8. 「あなた」タブ（文体・担当者の名前・スマホのコツ）

あなた自身のこと（文章の書き方・呼び名・使い方）は、「あなた」タブにまとめてあります。設定タブはAPIキーの設定だけです。

(1) あなたらしさ（文体・人物）設定
一人称（私／僕／俺）、口調・語尾、性格・立場、背景・経歴、想定読者、よく使う言い回し、書かないこと、そして文体の見本を入れられます。最初は全部空欄なので、ご自身の言葉で入れて「保存する」を押してください。
入れた内容は、9人の担当すべてに毎回渡されます。いちばん効くのは「文体の見本」にご自身のnoteやXの投稿をそのまま貼ることです（文の長さ・リズム・語尾を真似します）。
空欄でも大丈夫です。金額の基準日・「実質○円」の内訳・PR表記などの法令ルールは、9人の指示に元から入っています。
「いまAIに渡す文を見る」を押すと、実際にAIへ送られる文がそのまま表示されます。書き出し／読み込みで、別の端末へ移せます。保存先はこの端末の中だけです。

(2) AI担当者の名前
9人の担当に、あなたが呼びたい名前を付けられます（12字まで）。付けた名前は作業画面の9つの枠・実行ログ・オフィス一覧の表示に使われます。「ネタ係」「書き手」「最後のチェック係」など、分かりやすい名前をどうぞ。空欄にすれば元の名前に戻り、「全部もとの名前に戻す」ボタンもあります。
表示だけが変わり、AIへ送る役割の指示の中身は変わりませんので、品質は落ちません。

(3) スマホで使うときのコツ
4つあります。(1) 生成中は画面を閉じない（他のアプリに切り替えると止まります。中止しても「続きから再開」で終わった分を再利用できます）。(2) ホーム画面に追加すると1タップで開けます（iPhoneでは、7日間開かないと設定が消えるSafariの仕様を避けられます）。(3) 充電しながらまとめて仕込む。(4) 入力は「✎ 大きく入力する」から。キーボードのマイクボタンで音声入力も使えます。

9. noteに投稿する

段階やること
画像「図解・画像」タブの指示でアイキャッチ（1280×670px）を1枚用意。自分で撮った写真が一番強い
貼るnoteにログイン → [投稿] → [テキスト] → 見出し画像・タイトル・本文を貼る（「本文をコピー（note用）」ボタンが使えます）
タグ[公開設定] → ハッシュタグ3〜5個（例: #スマホ #料金見直し #乗り換え）
販売[販売設定] で無料／有料を選ぶ。有料なら価格（100円〜）と有料エリア設定
公開[投稿する] → 公開後、「このラインより上のエリアが無料で表示されます。」の位置を確認
告知「SNS投稿」タブのX投稿文をそのまま使う

有料ラインは「段落の直下」にしか引けません。先に本文でEnterを押して段落を作り、[＋] → [有料エリア指定] を選びます。

10. 仕事のルール（通信分野の7か条）

  • 金額には基準日を書いた（例: 2026年9月時点）
  • 「実質◯円」には内訳（端末代金・割引・ポイント還元・支払い回数）を書いた
  • キャンペーンには終了日と条件を書いた
  • 契約条件の注意書き（契約期間・解約費用・事務手数料）を入れた
  • 「最安」「No.1」「絶対」を使っていない
  • アフィリエイトのリンクに「PR」「広告」を明記した
  • あなたの一次情報（店頭体験）が本文に1つ以上入っている
特定のキャリア・店舗・個人を貶す表現は入れないでください。事実と条件だけで比較します。あなたの職業上の立場を守るためでもあります。
また、キャリア・代理店のアフィリエイト規約には「有料コンテンツ内での掲載可否」が個別に定められていることがあります。有料記事にアフィリエイトを併用する前に、提携先の規約をご確認ください。

11. スマホ・タブレットで使う

同じファイルがそのままスマホでも動きます（インストール不要）。画面幅が狭いときは、自動でスマホ向けの表示に切り替わります。

スマホ向けの工夫内容
画面下の固定バー作品を開くと、画面の下に「承認／却下／コピー／加筆を保存」が固定されます。長い本文をスクロールしても、いつでも押せます
1列レイアウトストック一覧と本文を横並びにせず、縦に並べます。指の届く範囲で操作できます
工程ボードを2〜4列9つの役割の進み具合を、狭い画面でも一望できます
入力欄を16pxにiPhoneで入力欄をタップしたときに、勝手に画面が拡大されるのを防ぎます
ボタンを44px以上に指で押しやすい大きさにしています
タブは横スクロール「記事本文」「検査レポート」などのタブを、折り返さず横に流して選べます
コピーの代替手段コピーが使えない端末では、編集欄を長押し→全選択→コピーを案内します
いちばん大事な注意：生成中は画面を閉じないでください。
スマホでは、画面が暗くなったり他のアプリに切り替わると、ブラウザが止められて処理が中断します。この仕組みは、対応している端末では画面が眠らないようにロックをかけ、画面の上の方に注意書きも出します。
それでも中断した場合は、画面右下の 「前回の続きがあります → 続きから再開」 を押してください。終わった役割は再利用されるので、AIの呼び出し回数を使いません。

スマホで快適に使う3つのコツ

  1. ホーム画面に追加する。ブラウザのメニューから「ホーム画面に追加」を選ぶと、アプリのように1タップで開けます
  2. 電源につないでおく。待ち時間があるので、まとめて仕込むときは充電しながらが安全です
  3. 長時間のスリープ設定を長めに。端末の設定で画面ロックまでの時間を延ばすと、中断のリスクが下がります

ストックの引き継ぎ（端末を変えるとき）

ストックはブラウザの中に保存されるので、端末を変えると引き継がれません。そこで引き継ぎ用のバックアップを用意しました。

  1. 「まとめて仕込む」欄の 「バックアップ（引き継ぎ用）」 を押す → JSONファイルが保存されます
  2. 新しい端末で同じファイルを開き、「バックアップを読み込む」 を押して、そのJSONファイルを選ぶ
  3. 今のストックと合流します（同じ作品はバックアップ側を優先）

※ Markdownの「ストックを書き出す」は人が読む用で、読み込みはできません。引き継ぎには JSON のバックアップをお使いください。

12. 止まったときの直し方

こんな症状原因と対処
429 と出た回数の使いすぎ（あなた側）。20〜30分待つ。1日分の上限は日本時間の夕方ごろにリセットされます
503 と出たGoogle側の混雑。4〜6秒待って自動で再挑戦します。それでも続くときは10分置くか、時間帯を変える（朝が狙い目）
404 と出たモデルの廃止。自動で別のモデルに乗り換えます（何もしなくてOK）
途中で止まった画面右下に 「前回の続きがあります → 続きから再開」 が出ます。作った役割は再利用されるので、回数を使いません
急に遅くなった慎重モード（6秒間隔）が働いています。正常です
ストックが消えたブラウザのデータを消すと消えます。「バックアップ（引き継ぎ用）」でJSONを保存しておいてください（読み込みで復元できます）
スマホで画面が暗くなり止まった端末が眠ると中断します。画面ロック時間を延ばし、電源につないで実行してください。止まっても「続きから再開」で回数を使わずに続けられます

この手引きは通信・モバイル版です。ファイルの意味は START_HERE.md、運用の考え方は 運用ガイド_モバイル.md にあります。

API設定が消えるときの直し方（キーの固定）

更新するたびにキーを聞かれる場合は、原因は次のどちらかです。

  1. 開いているURLが毎回ちがう：ブラウザの保存領域は「サイトごと」に分かれています。URLが1文字でも違うと別の場所とみなされ、キーは見つかりません。ブックマークとホーム画面は、必ず同じURLにしてください。
  2. ブラウザがサイトデータを保存しない設定：シークレットモード、または「終了時にサイトデータを削除」が有効だと、閉じた時点で消えます。

解決策A：サイト共通設定（config.js）─ おすすめ

リポジトリの config.js にキーを1回書けば、全ページ・全端末で同じ設定になります。ブラウザの保存領域を使わないので、更新しても消えません。

  1. GitHubで config.js を開き、右上の鉛筆マーク（Edit）を押す
  2. key: "" の "" の中に、あなたのキー（AIza…）を貼り付ける
  3. 下の「Commit changes」を押す
  4. 1〜2分待って、ページを強制再読み込み（PCは Ctrl+Shift+R）
重要：このファイルは公開リポジトリに置かれるため、URLを知っている人は中身を読めます。 キーを書く場合は、このサイト専用のキーを新しく作り、請求（有料プラン）を有効にしないことを強くおすすめします。 Google公式も「APIキーはパスワードと同じ扱いに」としています。

解決策B：設定コードで移す（人に見せない）

「キーを設定」の画面にある「更新するとキーが消えるとき／別の端末に移すとき」を開きます。「書き出す」を押すと1行のコードが出ます。それをコピーし、別の端末の同じ欄に貼って「読み込む」を押せば、キーと設定がまとめて移ります。このコードは人に見せないでください（キーそのものが入っています）。

明暗（ダーク／ホワイト）の切り替え

画面右下の丸いボタン（◐）を押すたびに、暗い配色と明るい配色が入れ替わります。運用ボードでは上部タブの右端にも「表示：暗／表示：明」があります。選んだ配色は記憶されます。
