SETUP

APIキーを入れる（最初の1回だけ）

  1. Google AI Studio を開いてログイン
  2. 「APIキーを作成」を押して、出てきた AIza… をコピー
  3. 下の欄に貼り付けて「保存して確認」
更新するとキーが消えるとき／別の端末に移すとき
A. サイト共通にする（おすすめ・更新でも消えません）
リポジトリの config.js を1回だけ編集して、key: "" の中にあなたのキーを書きます。 PCでもスマホでも、全ページが同じキーで動きます。ただし公開リポジトリなので、URLを知っている人は中身を読めます。 このサイト専用のキーを作り、有料プランにしないでください。

B. 設定コードで移す（端末ごとに1回・人に見せない）
下の枠へ「書き出す」→ 出たコードをコピー → 別の端末で貼って「読み込む」。
無料プランの場合：1分・1日あたりの回数に上限があります。慎重モード（6秒間隔）を最初からONにしています。また無料プランでは入力内容がGoogleの製品改善に使われます。売るための企画を出したくない場合は有料プラン（従量課金）をご検討ください（出典: Gemini API 料金ページ）。
MOBILE

スマホで使うときの3つのコツ

  1. 画面を閉じない。生成中に画面が暗くなったり、他のアプリに切り替わると、ブラウザが止められて中断します。中止しても 「続きから再開」で、終わった役割は再利用できます。
  2. ホーム画面に追加すると楽です。ブラウザのメニューから「ホーム画面に追加」を選ぶと、アプリのように1タップで開けます。
  3. 充電しながらが安全です。待ち時間があるので、まとめて仕込むときは電源につないでください。
  4. 入力は「✎ 大きく入力する」から。全画面の大きな入力欄が開きます。スマホのキーボードのマイクボタンで音声入力も使えます。打った内容はその場で元の欄に反映され、自動保存されます。「貼り付け」ボタンやMarkdownの記号・店頭体験の型もボタン1つで入ります。
左下のボタンが画面下に固定されます（承認／却下／コピー／加筆を保存）。
